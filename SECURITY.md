# Security policy

## Reporting a problem

Please report security problems **privately**, never in a public issue or on Discord:
use GitHub's private reporting for this repository
([Report a vulnerability](https://github.com/Kyle-Hosman/xdj-az-emu/security/advisories/new),
under the Security tab).

Include what is affected (version, firmware, platform), how to reproduce it, and what
an attacker could do with it. The maintainer aims to answer within a week. Please give the
maintainer a reasonable time to ship a fix before you publish details; you will be
credited in the release notes unless you ask not to be.

## Scope

The emulator: the AZ-EMU app, the tools in `tools/`, the guest components and the image build. The emulator runs on your own computer; a problem in the mods it runs belongs in [xdj-az-mods](https://github.com/Kyle-Hosman/xdj-az-mods/security/advisories/new).

## Supported versions

The latest commit on `main`.
